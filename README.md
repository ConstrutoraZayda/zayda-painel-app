# Zayda Painel

Página de entrada que faz o painel da Zayda Construtora abrir como app no iPhone e no iPad, com o ícone da Zayda.

Ela só carrega o painel publicado no Google Apps Script dentro de um iframe e repassa os parâmetros da URL. Não guarda dados: o acesso continua protegido pelo código do painel.

Sempre que o `index.html` mudar, aumente o número em `versao.txt` e em `VERSAO_ENTRADA` no `index.html`, juntos.
